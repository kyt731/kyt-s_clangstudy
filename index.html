1. 반복문

while문

while문은 조건식이 참인 동안 반복 실행되는 반복문이다.

int i = 1;
int sum = 0;

while (i <= 10) {
    sum += i;
    i++;
}

printf("%d", sum);
조건을 먼저 검사하므로, 처음부터 조건이 거짓이면 한 번도 실행되지 않는다.

do-while문

do-while문은 반복문 내부 코드를 먼저 실행한 뒤 조건식을 검사한다.

int i = 1;

do {
    printf("%d\n", i);
    i++;
} while (i <= 5);
do-while문은 조건이 거짓이어도 최소 한 번은 실행된다. while 뒤에는 세미콜론을 붙여야 한다.

for문

for문은 반복 횟수가 정해져 있을 때 주로 사용한다.

for (int i = 1; i <= 10; i++) {
    printf("%d ", i);
}

중첩 for문

중첩 for문은 for문 안에 또 다른 for문을 작성하는 방식이다.

for (int i = 2; i <= 9; i++) {
    for (int j = 1; j <= 9; j++) {
        printf("%d x %d = %d\n", i, j, i * j);
    }
}

2. 사용자 정의 함수

사용자 정의 함수는 자주 사용하는 기능을 따로 만들어 필요할 때 호출할 수 있게 한 것이다.

int add(int a, int b) {
    return a + b;
}

int main() {
    printf("%d", add(3, 5));
    return 0;
}
함수는 반환값의 유무와 매개변수의 유무에 따라 형태가 나뉜다.

재귀 함수

재귀 함수는 함수 내부에서 자기 자신을 다시 호출하는 함수이다.

long long fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
재귀 함수는 종료 조건이 반드시 필요하다.

3. 난수 함수

난수 함수는 임의의 값을 생성할 때 사용한다.

#include <stdlib.h>
#include <time.h>

srand(time(NULL));

int a = rand() % 10 + 1;
rand() % 10은 0부터 9까지의 값을 만들고, rand() % 10 + 1은 1부터 10까지의 값을 만든다.

4. 지역 변수, 전역 변수, static, extern

지역 변수

지역 변수는 함수나 블록 내부에서 선언되며 해당 범위 안에서만 사용할 수 있다.

전역 변수

전역 변수는 함수 외부에서 선언되며 여러 함수에서 사용할 수 있다.

static 변수

static 변수는 함수가 종료되어도 값이 유지된다.

void test() {
    static int count = 0;
    count++;
    printf("%d\n", count);
}

extern

extern은 다른 파일에 선언된 전역 변수나 함수를 사용할 때 작성한다.

5. 배열

배열은 같은 자료형의 데이터를 여러 개 저장하는 자료 구조이다.

int a[5] = {10, 20, 30, 40, 50};

printf("%d", a[3]);
배열의 인덱스는 0부터 시작한다. int a[5]의 인덱스 범위는 0부터 4까지이다.

2차원 배열

int arr[3][2] = {
    {1, 2},
    {3, 4},
    {5, 6}
};

printf("%d", arr[2][1]);
2차원 배열은 arr[행][열] 형태로 접근한다. 위 코드에서 arr[2][1]의 값은 6이다.

6. 문자와 문자열

문자는 작은따옴표를 사용하고, 문자열은 큰따옴표를 사용한다.

char ch = 'A';
char str[6] = "hello";
문자열의 마지막에는 널 문자 \0이 저장된다. 따라서 "hello"를 저장하려면 최소 6칸이 필요하다.

문자열 처리 함수

  • strlen(s): 문자열 길이를 구한다.
  • strcpy(s1, s2): s2를 s1에 복사한다.
  • strcat(s1, s2): s2를 s1 뒤에 붙인다.
  • strcmp(s1, s2): s1과 s2를 비교한다.
  • strchr(s, c): 문자열 s에서 문자 c를 찾는다.
  • strstr(s1, s2): 문자열 s1에서 문자열 s2를 찾는다.
#include <string.h>

char a[10] = "abc";
char b[10] = "ab";

strcat(b, "c");

if (strcmp(a, b) == 0)
    printf("같음");
else
    printf("다름");

7. 구조체와 공용체

구조체

구조체는 서로 다른 자료형의 데이터를 하나로 묶어 관리할 수 있는 자료형이다.

#include <string.h>

struct Student {
    char name[20];
    int num;
    float score;
};

struct Student s;

strcpy(s.name, "minsu");
s.num = 1;
s.score = 95.5;

공용체

공용체는 구조체와 비슷하지만 모든 멤버가 같은 메모리 공간을 공유한다.

union Data {
    int num;
    float fnum;
    char ch;
};
구조체는 각 멤버가 서로 다른 메모리 공간을 사용하고, 공용체는 같은 메모리 공간을 공유한다.
